\# NEXUS EXECUTION RULESFor an assigned task, work autonomously.Allowed routine actions:\- inspect files\- search code\- read documentation\- create required files\- edit files\- refactor code inside task scope\- run builds\- run tests\- run linting\- run formatting\- inspect git status\- inspect git diff\- fix errors caused by current work\- repeat build/fix/test cyclesDo not stop for routine development questions.Before modifying code:1\. Read repository CLAUDE.md.2\. Read MILESTONE-MASTER.md.3\. Read CURRENT-DEVELOPMENT.md.4\. Identify task ID.5\. Determine affected files.6\. Check for active development conflicts.7\. Proceed only when no conflict exists.During implementation:IMPLEMENT↓BUILD↓TEST↓FAIL?├── YES → diagnose → fix → build again└── NO → continueContinue until complete or an escalation condition occurs.
