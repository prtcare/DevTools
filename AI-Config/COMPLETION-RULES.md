\# NEXUS COMPLETION RULES



A task is not complete merely because code was written.



Before reporting completion:



1\. Build must succeed.

2\. Relevant tests must run.

3\. New errors caused by the change must be resolved.

4\. git diff must be reviewed.

5\. Unrelated files must not be changed.

6\. CURRENT-DEVELOPMENT.md must be updated.

7\. MILESTONE-MASTER.md status must be updated if appropriate.



Completion report must include:



\- Task ID

\- Work completed

\- Files created

\- Files modified

\- Build result

\- Test result

\- Documentation updated

\- Remaining issues

\- Recommended next task
